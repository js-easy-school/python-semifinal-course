# Питон — практикум Python и алгоритмов

## Открыть на телефоне или компьютере

Онлайн-курс публикуется на GitHub Pages: https://js-easy-school.github.io/python-semifinal-course/

На смартфоне достаточно открыть ссылку в современном браузере. Компьютер владельца может быть выключен. Первый запуск Python скачивает примерно 14 МБ. Код исполняется на телефоне, а прогресс хранится в его браузере. Между устройствами прогресс переносится кнопками экспорта и восстановления — автоматической синхронизации нет.

## Как начать локально

1. Дважды нажми **Открыть курс.cmd** в этой папке.
2. Откроется **http://127.0.0.1:8766/**. Пока занимаешься, оставь окно сервера открытым (его можно свернуть).
3. Выбери маршрут **7 дней** и нажми **Открыть первый урок**.
4. Прочитай теорию, выполни задания «Попробуй сам» прямо в ней, ответь на мини-вопрос и перейди во вкладку **02 · Решить**. Если задача кажется трудной, пройди ступеньки темы над вкладками: разминка → по образцу → без образца → основная задача.
5. Пиши код справа. Данные для `input()` вводи в поле **Входные данные**. Нажми **Запустить**, затем **Проверить решение**.

Для локального запуска интернет после установки не нужен. Онлайн-версии нужен интернет для загрузки файлов. Открывать локальный index.html двойным щелчком не следует: движок Python требует локального HTTP-сервера. Весь комплект движка уже лежит в `vendor/pyodide`. Сервер использует установленный Python 3.12, учебный код исполняется **в браузере на Python 3.14.2**, а не в Windows.

## Что добавлено для первого знакомства

- Раздел «С нуля»: шесть коротких объяснений — команды, переменные, текст и числа, ввод, отступы и проверка.
- Для каждой из 30 тем: зачем она нужна, бытовое сравнение, как узнать подходящую задачу, разобранный числовой пример и словарь команд.
- 30 отдельных разминок на 3–5 минут перед основными задачами.
- 60 ступенек — по две в каждой теме между разминкой и основной задачей. Первая решается по образцу: в редакторе уже есть заготовка, нужно дописать одну-две строки. Вторая решается без образца и готовит к основной задаче. У каждой ступеньки своя теория, пример, разбор на числах, словарь команд, мини-вопрос, три подсказки, решение и 6–8 тестов.
- Полоса «Ступеньки темы» на каждом уроке показывает путь разминка → по образцу → без образца → основная задача и отмечает пройденное. После решения появляется ссылка на следующую ступеньку, а при неудаче в основной задаче — на ступеньку попроще.
- Подсказки к типичным ошибкам вывода: лишний текст рядом с ответом, пустой вывод, `None` из функции без `return`, список со скобками, дробное `5.0`, другой регистр букв, лишние или недостающие значения, другой порядок, ответ на 1 больше или меньше во всех тестах.
- Кнопка «Запустить» сравнивает вывод с примером из условия, если во вводе стоит этот пример.
- Решение по одной строке: после подсказок можно открывать решение построчно с пояснениями, не заглядывая сразу в полный разбор.
- Построчные объяснения всех 130 решений.
- Подробный разбор каждой из 30 тем во вкладке **01 · Понять**: 130 разделов с объяснениями, 103 примера кода с настоящим выводом, 35 таблиц «по шагам», 49 типичных ошибок (неверный код, его настоящий результат и исправление) и итог «Запомни».
- 102 задания «Попробуй сам» прямо внутри теории: 30 «предскажи вывод», 30 «допиши код» с пропуском в строке, 30 мини-задач и 12 «исправь ошибку» в маленьком редакторе. Код заданий проверяет тот же Python в браузере, что и основные задачи; есть подсказка и показ ответа, выполненные задания отмечаются, а общий счёт виден на главной. На разминках и ступеньках подробная теория темы открывается кнопкой, на основном уроке она развёрнута.
- Кнопки отступа, скобок, кавычек и новой строки для экранной клавиатуры.
- Цветовые темы — кнопка **Тема** в верхней панели: «Мята» (зелёная, по умолчанию), «Небо» (голубая), «Лаванда» (сиреневая), «Персик» (тёплая) и мягкая тёмная «Сумерки» (сине-сиреневая, не чёрная). Выбор запоминается в браузере и сразу применяется в других открытых вкладках; редактор кода тоже меняет оттенок.

## Реалистичный режим подготовки

**7 дней:** примерно 2–3 часа в день. Пройди базу и основные приёмы; углубление оставь после уверенных самостоятельных решений. Отдельно выдели 3 часа на пробный тур и 30–45 минут на разбор.

**14 дней:** примерно 1,5–2 часа в день; последнему дню со сложными темами может потребоваться больше времени. Это общий учебный маршрут, он **выходит за сохранённый период подготовки**.

Каждый день: 10 минут повторения вчерашних задач без подсказок; короткая теория; самостоятельная попытка 15–25 минут; одна подсказка при затруднении; после разбора — переписать решение по памяти. Не нужно пытаться выучить шаблоны всех сложных алгоритмов за один вечер.

Проверки на сайте курса учебные. Они не доказывают правильность для всех возможных данных, не имитируют производительность других компьютеров и не проверяют асимптотику автоматически. Обсуждение сложности и ограничения входа приведены у каждой задачи.

## Прогресс и пробные туры

Данные хранятся только в localStorage браузера: отдельно для онлайн-сайта и для адреса **127.0.0.1:8766**. `localhost:8766` и другой браузер имеют отдельное хранилище. При очистке данных браузера прогресс исчезнет; заранее скачай резервную копию. Импорт заменяет текущий прогресс после подтверждения. Активный таймер из резервной копии не переносится.

Пробный тур запускается только отдельной кнопкой в курсе. Таймер не останавливается при закрытии вкладки. Задача засчитывается только при совпадении ответов во всех её учебных тестах. Разбор во время активного тура скрыт; это режим самопроверки, а не защищённый экзамен. При новом туре прежние тексты этого комплекта сохраняются в записи тура (`previousDrafts`) и доступны в экспорте прогресса.

## Технические сведения

Статическая веб-страница, CodeMirror 6, Lucide, локальная Pyodide 314.0.7. Сервер слушает только `127.0.0.1`, не исполняет присланный код и не предоставляет API записи файлов. Python работает в Web Worker; его виртуальная файловая система не равна диску Windows. Автоматической установки внешних пакетов нет. Локальная версия не делает внешних сетевых запросов. Онлайн-версия скачивает статические файлы с GitHub Pages; код и заметки на сервер не отправляются.

- [Pyodide: Web Workers](https://pyodide.org/en/stable/usage/webworker.html)
- [Официальный учебник Python](https://docs.python.org/3/tutorial/)

Исходники: `app.js`, `beginner.js`, `theory.js` (подробная теория и задания «Попробуй сам»), `editor.js`, `worker.js`, `style.css`, `build_content.py` (уроки и пробные туры), `beginner_content.py` (объяснения для новичков и разминки), `practice_content.py` (ступеньки), `theory_content.py` (подробная теория и практика в ней). Сгенерированное содержимое: `curriculum.json`. Старый локальный прототип и пользовательские резервные копии исключены из Git и публичной сборки.

Для изменения интерфейса: `npm install`, затем `npm run build`. Все цвета заданы переменными в начале `style.css`: блок `:root` — тема «Мята», блоки `:root[data-theme=…]` — остальные темы; `theme.js` применяет сохранённую тему до отрисовки страницы. Для изменения уроков: отредактировать `build_content.py`, `beginner_content.py`, `practice_content.py` или `theory_content.py`, затем `python build_content.py`. В `theory_content.py` выводы примеров, ответы «предскажи вывод» и ожидаемые ответы заданий не пишутся вручную: сборка запускает код и сохраняет настоящий результат, а заодно проверяет, что эталоны проходят свои проверки, а заготовки мини-задач — нет. Для проверки всех решений, заготовок кода, структуры заданий и блоков теории: `python tests/verify_content.py`. При обновлении сайта поменяй метки `?v=` у изменённых файлов в `index.html` (`style.css`, `theme.js`, `dist/app.js`) и в `app.js` (загрузка `curriculum.json`), чтобы браузеры не взяли старую копию из кэша.

Проверено: все 706 тестов на CPython и Pyodide; все примеры, ответы и эталоны 102 заданий теории на CPython и в Pyodide 3.14.2 (выводы и тексты ошибок совпадают); неправильный ответ, синтаксическая ошибка, тайм-аут и восстановление движка; сохранение черновика; мини-вопросы и подсказки; таймер, баллы и завершение пробного тура; поиск; варианты маршрута; интерфейс 1440×1024 и 390×844. Снимки находятся в `tests`.

## Публикация

Сайт публикуется стандартным GitHub Pages из ветки `gh-pages`. В `main` находятся исходники. Готовые файлы собираются локально через `python tools/package_site.py` после `python tests/verify_content.py` и `npm run build`. Для обновления сайта нужно перенести содержимое `_site` (включая `.nojekyll`, без служебной папки `.git`) в ветку `gh-pages` и отправить изменения на GitHub. Изменения только в `main` сайт не обновляют. В публикацию не входят логи, история упражнений, тестовые резервные копии, старый прототип и локальные пути.
